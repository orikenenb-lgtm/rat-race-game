# מירוץ העכברים 🐀💰

משחק לוח תלת־ממדי שמלמד איך יוצאים ממירוץ העכברים: בונים הכנסה פסיבית מנכסים עד שהיא עוברת את ההוצאות.

**לשחק:** https://orikenenb-lgtm.github.io/rat-race-game/

## מה יש
- 4 עולמות, כל אחד עם מכניקה שמלמדת משהו אחר:
  - **השכונה**: נכס מול התחייבות
  - **העיר הגדולה**: ריבית ומינוף
  - **הנמל הגלובלי**: דולר וגידור
  - **עמק העתיד**: השקעות אנג'ל ונתינה
- כוכבים, עולמות נעולים, הישגים, תארים וכלי משחק לפתיחה
- אתגר יומי (ספרינט של 24 חודשים) עם רצף ימים, אתגר שבועי, קבוצות עם קישור הזמנה, אתגרים קבוצתיים וקישורי "דו־קרב"
- כל השחקנים באתגר מקבלים אותן קוביות ואותם קלפים. המשחק נשמר בשרת אחרי כל צעד, כך שאי אפשר להתחיל מחדש ולדעת מה יבוא.
- מנטור "אבא עשיר" בכל החלטה (כולל הקראה בעברית)

## מבנה
- `index.html`, `css/`, `js/`: המשחק (ES modules, Three.js מ-CDN, בלי שלב build)
- `js/engine.js` + `js/worlds/`: מנוע טהור ודטרמיניסטי ונתוני העולמות. ראו `docs/ENGINE.md`.
- `js/net.js`: Supabase. סכמה `game`; הדפדפן קורא רק לפונקציות `rr_*`.
- `assets/`: מודלים מ-Blender (`blender/`)
- `tools/sim.mjs`: סימולציית איזון (`node tools/sim.mjs 600`), דוח ב-`tools/balance-report.md`
- `tests/`: `node tests/engine.test.mjs`, `node tests/progress.test.mjs` ובדיקות Playwright
- `docs/`: מסמך עיצוב, תיעוד מנוע ודוח QA
