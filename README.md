# מירוץ העכברים 🐀💰

משחק לוח תלת־ממדי שמלמד איך יוצאים ממירוץ העכברים: בונים הכנסה פסיבית מנכסים עד שהיא עוברת את ההוצאות.

## מה יש
- לוח 3D (Three.js) עם נכסים שנבנו ב-Blender (`build_assets.py`)
- 4 מקצועות, עסקאות נדל"ן/עסקים/מניות/קריפטו, הוצאות מפתות, אירועי שוק
- מנטור "אבא עשיר" (כולל הקראה בעברית)
- קבוצות עם קוד/קישור הזמנה, אתגרים קבוצתיים ואתגר שבועי — כולם מקבלים אותן קוביות ואותם קלפים
- שרת: Supabase (סכמה `game`, גישה רק דרך פונקציות `rr_*`)

## לבנות מחדש את המודלים
```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup --python build_assets.py
```
