## Reading, tuning done, and why some gates are not met (T2 engine lane)

Tuning applied (knob order of spec §13.5): DD w1 priors .45/.32/.15/.08 with r2 cf .45–1.00 and r3 −0.10–0.75 (spec .50/.33/.13/.04, .50–1.00, .10–.80); repair = down × (0.05 + 0.25u) (spec 0.1 + 0.4u — punitive in the big-down worlds); evaluator weights: concave 🔋 and 😊 values, a 36-month cashflow horizon in passive-income worlds, owner-run business 🔋 cost + the one cushion rule on `start`, a refused offer costs ½ of the lost deal, an 80-month horizon for selling income assets in passive worlds, ties without a card default fall to the safe "continue" option. Cycle amp 0.7 (w1) / 1.3 (w4) was tried and had no measurable effect, so the spec values stay.

Measured diagnostics (12 seeds × each character, guideTapper, same seeds):
* **A1 / A3 / A8 conflict.** The highlight-follower and the smart player move together: the smart − guideTapper gap stays 12–25 points in w1 and w4 whatever the difficulty knob (w1 DD gentle → guide 69% / smart 81%; harsher → 58% / 79%). The largest single cost of the tapper is its random choice on personal / values life events (no highlight there, by design): choosing the cheapest option on those cards instead raises guideTapper w1 58% → 83% and w2 56% → 78%. Values events (car, health) lost their v3 highlight in T2 (§10.3), which adds to it.
* **A2b (naive).** w1 is easy for "believe the seller, buy everything, plan work, cheapest life option": 92% in time. The cheapest-life-option habit and never paying 🔋 for anything carry it; DD alone cannot push it down without pushing the guide below 65%.
* **A5.** `f:ops` is never worse than `f:none` because the T2 smart policy (hint level, no highlight) never opens a managed business, so the ops focus is never available — a sim-policy gap, not an engine one (fix: give smart v3's business-offer rule; it changes every smart number, so the matrix must be re-run).
* **A7.** `plan:study` is top in every appearance until the degree is done (study early is the dominant habit since v3); w2 `upgrade:trim` and w3 `business:start` also flag. Personal/values life cards always have a money-top option but score 100 for every choice.

Recommendations for the director: (1) accept A1/A3 as a pair conflict for w1 and w4, or let the guide highlight the cheapest option on values events (car/health) and re-measure; (2) treat A2b as a w1 lesson-design question (life-event costs), not a DD question; (3) a follow-up sim pass for smart's business rule (A5) and a study-plan rebalance (A7) — both need one more 1-hour matrix run.
