# ADMIN_CHAT — כלי המנהל וצ'אט בחדרים חיים

## סיכום בעברית (לבעל המשחק)

**מה ביקשת:** רק אתה, כמנהל, פותח את כל המפות ועושה הכול: מוציא שחקנים, חוסם אותם ומעיף אותם. ובמשחקים אונליין יש צ'אט.

**מה נבנה.** הכול עדיין טיוטה. שום דבר לא הופעל בייצור.

### מה רק אתה יכול לעשות

השרת בודק שאתה המנהל בכל פעולה, ולא סומך על הדפדפן. שחקן רגיל לא רואה את הכלים האלה. גם אם הוא מנסה לקרוא להם ישירות, הוא מקבל "רק מנהל המשחק יכול לעשות את זה".

- **כל המפות פתוחות:** אצלך כל 6 העולמות וכל המפות הבנויות פתוחים, וגם כל הכלים. מפות "בקרוב" נשארות סגורות.
  - זה קורה רק אחרי שהשרת מאשר שאתה המנהל.
  - שמירה שמישהו ערך ידנית בדפדפן כבר לא פותחת שום דבר. תיקנתי את זה.
- **השעיה (חסימה):**
  - איפה: פרופיל ← 🛡️ מנהל ← חיפוש שחקן ← "🛡️ ניהול".
  - כותבים סיבה ובוחרים משך: יום, 3 ימים, שבוע, חודש או לצמיתות.
  - לוחצים "להשעות" פעמיים.
  - שחקן מושעה:
    - לא יכול לפתוח חדרים או להיכנס אליהם.
    - לא יכול לכתוב בצ'אט.
    - לא יכול להצטרף לקבוצות או לפתוח קבוצה.
    - לא מופיע בטבלאות (יומי, שבועי, אתגרים).
    - יוצא מכל חדר פתוח.
  - הוא רואה הודעה ברורה: "החשבון שלך מושעה… אפשר להמשיך לשחק לבד".
  - אפשר לבטל השעיה בכל רגע, בכרטיס של השחקן או בלשונית "⛔ השעיות".
  - אי אפשר להשעות את עצמך.
- **להעיף מחדר:**
  - איפה: לשונית "🎲 חדרים חיים" ← "להוציא" ליד השחקן.
  - בחדר המתנה: המקום שלו מתפנה, והוא לא יכול לחזור עם הקוד.
  - באמצע משחק: הוא נחשב כ"פרש", ושאר השחקנים ממשיכים לשחק. אם לא נשאר אף אחד, החדר נגמר כרגיל.
- **לסגור חדר:** "לסגור את החדר". החדר מתבטל ואף אחד לא מדורג. השחקנים רואים "מנהל המשחק סגר את החדר".
- **להוציא מקבוצה:**
  - איפה: בכרטיס השחקן ← "להסיר מהקבוצה".
  - אם הוא הבעלים של הקבוצה, החבר הוותיק ביותר מקבל את הבעלות.
- **דיווחים מהצ'אט:**
  - איפה: לשונית "🚩 דיווחים בצ'אט".
  - שם רואים את ההודעה, מי שלח אותה, באיזה חדר, וכמה דיווחו עליה.
  - אפשר "להסתיר" אותה. היא נעלמת לכולם.
  - אפשר "להשעות לשבוע" את מי ששלח אותה.
  - רואים גם מי ניסה לשלוח קישור, טלפון או מילים לא יפות ב-24 השעות האחרונות. רק הסוג נשמר, לא הטקסט.
- **צ'אט של חדר:** בלשונית "חדרים חיים" לוחצים "💬 צ'אט", ורואים את כל ההודעות. אם אתה בעצמך בתוך החדר, יש לך שם "להסתיר" ו"להשעות" ליד כל הודעה.
- **יומן פעולות:**
  - כל פעולה שלך נרשמת, ואי אפשר למחוק או לשנות את היומן.
  - נרשמים גם קבלת קוד המנהל ומתנות ⚡.
- **בעל חדר (מארח)** יכול להוציא שחקן רק בחדר ההמתנה, לפני שהמשחק מתחיל. אחרי ההתחלה הוא כבר לא יכול.

**לחיצה כפולה:** כל פעולה הורסת דורשת לחיצה שנייה.
- הלחיצה הראשונה משנה את הכפתור ל"לחץ שוב לאישור". הוא נשאר כך 4 שניות.
- לחיצה כפולה מהירה מדי (פחות מ-0.32 שניות) לא נחשבת.

### הצ'אט בחדר — כללי הבטיחות (רוב השחקנים ילדים)

השרת אוכף את כל הכללים. הדפדפן רק מציג את התשובה שלו.

- **רק שחקני אותו חדר.** מי שהוצא מהחדר או הושעה, כבר לא בצ'אט.
- **עד 120 תווים** בהודעה.
- **אסור לשתף פרטי קשר:**
  - קישורים ואתרים (גם `site.com`, `example dot com`, `t.me/…`).
  - מספרי טלפון (7 ספרות ומעלה, גם עם רווחים, מקפים או ספרות ערביות).
  - מיילים.
  - `@שמות` ושמות של אפליקציות: אינסטה, סנאפ, טיקטוק, וואטסאפ, טלגרם, דיסקורד, פייסבוק.
- **בלי קללות ועלבונות** בעברית ובאנגלית.
  - גם עקיפות נחסמות: `f u c k`, `sh1t`, אותיות רחבות, ניקוד, תווים נסתרים.
  - הרשימה נמצאת במקום אחד: `game.chat_lists` ב-SQL. אם אתה רוצה להוסיף או להוריד מילה, צריך לשנות את הקובץ, והבדיקות משוות אותו לעותק ב-JS.
- **הודעה שנחסמת לא נשמרת ולא נשלחת.** השולח מקבל הסבר נעים בעברית, למשל: "אסור לשתף מספרי טלפון בצ'אט — שומרים על עצמנו 🙂".
- **קצב:** עד 5 הודעות ב-10 שניות, ועד 60 בשעה. גם ניסיונות שנחסמו נספרים.
- **משפטים מהירים** תמיד זמינים, בלשון ניטרלית: "בהצלחה!", "מהלך יפה 👏", "רגע, אני חושב/ת", "משחק טוב 🤝".
- **השתקה:** כל שחקן יכול "להשתיק" שחקן אחר. זה נשמר רק אצלו במכשיר.
- **דיווח:** "🚩 דווח" על הודעה של מישהו אחר. הדיווח מגיע אליך.
- **ההיסטוריה נשמרת 7 ימים** ואז נמחקת לבד, בלי משימה מתוזמנת.
- **הצ'אט לא נוגע במשחק:** לא בקוביות, לא בכסף ולא בתוצאות. נבדק בדפדפן: אחרי הודעה באמצע משחק, מצב המשחק לא השתנה.
- **בטלפון (360/390):** הצ'אט מקופל מאחורי כפתור "💬 צ'אט החדר", עם מונה הודעות חדשות.

## 2. SQL (draft) — requires the baseline + `20261123_admin.sql` (live) + `20261124_rooms.sql`; groups v2 optional

**New tables** (RLS on, no policies, no grants):
- `game.bans` (player pk, reason 2–200, by, until null = permanent).
- `game.mod_log` (append-only: UPDATE / DELETE / TRUNCATE raise `mod_log_append_only`; no FKs).
- `game.room_chat` (room, seat, player, text 1–120, hidden, hidden_by / at).
- `game.chat_reports` (msg, reporter) pk.
- `game.chat_blocked` (player, room, reason; never the text).

**Triggers (additive) on existing tables:**
- `room_seats` / `group_members` BEFORE INSERT → `banned`.
- `admins` / `energy_gifts` (kind admin) AFTER INSERT → mod log `claim` / `give`.

**Replaced functions** (same signature / volatility / security / ACL; proved by `admin_chat_sql`):
- `game.board`: the baseline body + one `not exists (active ban)` filter. The same JSON as the baseline body for any board without a banned player (tested against the original body).
- `game.room_purge`: + chat older than 7 days and refusal rows.

Every RPC takes `p_id, p_secret` first. Errors are raised codes (PostgREST 400 `{message: code}`). Chat refusals use the `game.room_fail` pattern: the refusal row commits, and the answer is 400 with the code.

| RPC | who | returns · errors |
|---|---|---|
| `rr_ban_status()` | anyone | `{banned, until ms\|null, permanent}` |
| `rr_room_chat_send(p_room, p_text)` | room members | `{id, at}` · `banned` · `room_not_found` · `not_in_room` (also admin-kicked) · `chat_closed` (> 30 min after the end) · `rate_limited` (5 / 10 s, 60 / h, refusals count) · refusals `chat_empty` `chat_too_long` `chat_email` `chat_link` `chat_phone` `chat_handle` `chat_bad_word` |
| `rr_room_chat_list(p_room, p_since)` | room members | `{msgs[≤ 40, id > since]{id, seat, nickname, text, at, me}, hidden[ids among the last 100], last}` |
| `rr_room_chat_report(p_msg)` | room members, not own | `{reported}` (idempotent) · `msg_not_found` `cannot_report_self` `rate_limited` (20 / h) |
| `rr_admin_ban(p_target, p_reason, p_days)` | admin | `{banned, until, rooms}` (sweeps open rooms) · `not_admin` `cannot_ban_self` `player_not_found` `bad_reason` `bad_days` |
| `rr_admin_unban(p_target)` | admin | `{banned:false}` · `not_banned` |
| `rr_admin_bans()` | admin | active bans `[{player_id, nickname, reason, until, at, by}]` |
| `rr_admin_player(p_target)` | admin | `{id, nickname, stars, joined, admin, ban, groups[], rooms[], blocked_24h, reported_24h}` |
| `rr_admin_rooms()` | admin | open rooms (≤ 50) with seats (player ids), chat / report counts |
| `rr_admin_room_chat(p_room)` | admin | last 100 messages incl. hidden (flagged), sender ids, report counts |
| `rr_admin_kick_room(p_room, p_target)` | admin | `{result: removed\|forfeit, status, needs_tick}` · `cannot_kick_self` `room_not_found` `room_not_open` `player_not_in_room` `seat_finished` |
| `rr_admin_close_room(p_room)` | admin | `{status:'cancelled'}` (end_reason `admin`, unranked) · `room_not_open` |
| `rr_admin_remove_from_group(p_group, p_target)` | admin | `{removed, group_deleted}` (groups v2 → its own path: ban until the code rotates + log) · `group_not_found` `member_not_found` |
| `rr_admin_delete_chat(p_msg)` | admin | `{hidden}` · `msg_not_found` |
| `rr_admin_reports()` | admin | `{reports[7 days], blocked[24 h]}` |
| `rr_admin_mod_log(p_before)` | admin | `{log[50], next_before}` |

**Mid-game kick:**
- `game.admin_seat_out` makes the seat `forfeit` (like leaving), sets `needs_tick` and adds the player to `rooms.kicked`, so they lose the chat.
- The next Edge `tick` (any member's client) closes the round, and the others play on.
- If no active seat is left, `tick` finishes the room (`all_done`, ranked as usual).
- A lone remaining player continues, or votes to cancel (existing rule).

## 3. Child-safety notes

- **Members only:** the same room, and an admin-kicked player is out of the chat.
- **No contact sharing:**
  - links / domains (incl. `dot`, `(dot)`, spaced dots, full-width), phones (≥ 7 digits after removing separators, Arabic-Indic digits), e-mails, any `@x`, social-app names;
  - Hebrew + English profanity and insults (folded: NFKC, invisible / bidi marks, niqqud, leet `0134578@$!|`, final letters, repeats, spaced single letters).
- **Kept out of the word list on purpose:**
  - identity words (`הומו`, `לסבית`), so kids can't be blocked for who they are;
  - ambiguous short words with innocent meanings (`כוס`, `זין` inside `הזין` / `מזין`, `חרא` inside `אחראי`); the tests cover these false positives.
- **Known limits:**
  - spelled-out numbers ("אפס חמש ארבע…");
  - creative new spellings;
  - images (none: text only);
  - moderation is after the fact: reports, hide, ban.
